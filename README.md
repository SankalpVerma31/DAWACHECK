## 📌 Overview

**DawaCheck** is a web application designed to help Indian consumers understand whether they are being charged more than the legally permitted price for medicines.

India's government sets legally binding **maximum ceiling prices** for hundreds of essential drug formulations under the **Drug Price Control Order (DPCO)**, enforced by the **National Pharmaceutical Pricing Authority (NPPA)**.

At the same time, **Jan Aushadhi Kendras** provide medicines containing the same active pharmaceutical ingredients at significantly lower prices.

However, these datasets are difficult for an ordinary customer to use while standing at a pharmacy counter.

### 💡 DawaCheck closes that gap in seconds.

Simply upload a photo of your pharmacy bill or enter the medicine details manually.

DawaCheck then:

> **Reads → Understands → Matches → Compares → Explains → Helps You Act**

# ✨ Key Features

| Feature | Description |
|---|---|
| 📷 **Bill OCR** | Upload a pharmacy bill and extract medicine information using Gemini Vision |
| ✍️ **Manual Entry** | Enter medicine details manually without requiring an API key |
| 🧬 **Salt-Level Matching** | Resolves medicine brands to their underlying active ingredient |
| 💰 **Price Comparison** | Compares the billed price against the estimated NPPA ceiling price |
| 🏥 **Jan Aushadhi Comparison** | Shows the price of the same molecule through Jan Aushadhi |
| 📍 **Kendra Locator** | Helps identify the nearest Jan Aushadhi Kendra |
| ⚖️ **Overcharge Detection** | Highlights potential cases where the billed price exceeds the applicable ceiling |
| 📊 **Confidence Score** | Displays the confidence of every medicine-to-formulation match |
| 📝 **NPPA Complaint Generator** | Automatically drafts a formal complaint letter |
| 📄 **PDF Export** | Download the generated complaint as a PDF |
| 🗣️ **Hindi & English** | Results can be presented in Hindi or English |
| 📤 **Savings Card** | Generate a shareable summary of potential savings |
| 🗺️ **Overcharge Heatmap** | Anonymous data points can contribute to a public visualization |
| ⚠️ **Ambiguity Detection** | Uncertain matches are surfaced instead of being silently accepted |
